# Setup

Let's get Folio set up in your browser.

Folio can be installed on Edge or Chrome, and potentially other Chromium-based browsers.

## Installing Folio Locally

1. Download the latest version of the extension from [GitHub](https://github.com/mcv-s/Folio/archive/refs/heads/main.zip).

2. Unzip the extension.

3. Go to your browser's extensions page.

4. Enable **Developer Mode** if it is not already enabled.

   ![Enable Developer Mode](https://mcv-s.github.io/folio/Images/DeveloperModeImage.png)

5. Select **Load Unpacked**.

   ![Load Unpacked](https://github.com/user-attachments/assets/76aefcd0-1b92-4b15-a7c2-3a8a6a1dd261)

6. Select the unzipped Folio extension folder and you're ready to go!


## Getting started

Now that you have folio installed, we reccomend getting to know it a bit. 

Explore the settings and enable different addons - and most importantly, customize your new tab page exactly how you want it!
