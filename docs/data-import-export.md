# Data - Importing & Exporting

> _How to save and load your settings_

Folio has a lot of settings, and it would be a pain to have to lose them if the extension bugs and you have to reload it.

If you move devices, it may be annoying to re-configure all your desired settings.

This is why Folio allows you to import and export your data to your device's file system.

<br>

Simply scroll down to the Advanced section in settings, and press the import or export buttons under the Data section.

<br>

![Data Section](/Images/Data.png)


## Exporting Data 

To export your data, press the export button (the one with the down arrow) - your device should download a "folio-backup.json" file. This is all of your Folio settings.


## Importing Data

To import your data, press the import button (the one with the up arrow) - your device should open a file picker and ask you to choose a ".json" file.

When you select a file, Folio will attempt to load the configuration settings in it. This WILL overwrite the settings which you have selected.
