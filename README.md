Folio is a Chromium extension which adds several features to your web browser. It supports:

- An AI search bar
- Custom backgrounds
- Random backgrounds
- Widgets/Integrations


. . . and a lot of simplicity, because most new tabs just have too much. <br><br>

Here's our privacy policy: https://mcv-s.github.io/folio/privacy.html


<br><br>
# Downloading & Using


- Download the latest version of the extension from github [here.](https://github.com/mcv-s/Folio/archive/refs/heads/main.zip "github.com/mcv-s/Folio/archive/refs/heads/main.zip") 
- Unzip the extension
- Go to your browser's extensions page
- You may need to enable developer mode if it's not already enabled:

 <img width="308" height="123" alt="image" src="https://github.com/user-attachments/assets/767f98cd-f37e-45d5-9150-d7fd73e03e42" /><br>
 
- Select Load Unpacked

<img width="357" height="59" alt="image" src="https://github.com/user-attachments/assets/76aefcd0-1b92-4b15-a7c2-3a8a6a1dd261" />

- Select the unzipped extension folder and you're good to go!
